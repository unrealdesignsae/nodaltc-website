# Active design direction

The user rejected the initial split stock-photo hero and asked for the original Nodal style, with a full-screen futuristic drone-scanning image. Those early concepts are superseded.

Reference: https://nodaltc.com and the source at original commit 07db385. Original palette #070a0f / #0d1117 / #00d4ff; Inter body, Rajdhani headings, Share Tech Mono technical labels. Retained original logo.

The revised page places a cinematic drone scan across the entire opening viewport, with GPS equipment, a festival site and cyan digital geometry. Copy is composed over dark negative space. Transparent navigation, restrained title weight, fine cyan borders, dark process cards and an outlined Nodal footer carry through the original visual language.

The ten-section content sequence is retained from the client PDF. Drone Site Scan remains an add-on, with licensed partner pilots and permit wording unchanged. The generated hero is explicitly labelled illustrative, following the user's direct request for generated drone imagery.

Mobile uses a full-height crop of the same scene, a dark readability overlay, stacked process cards and a persistent contact action. Reduced-motion preference disables animations.
